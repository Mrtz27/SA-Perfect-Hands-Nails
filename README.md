*SA Perfect Hands & Nails es un proyecto de desarrollo web diseñado para un negocio de servicios de belleza especializado en el cuidado y embellecimiento de manos y uñas. Su propósito es presentar de manera organizada y atractiva los servicios del negocio, ofrecer a los clientes una experiencia de navegación sencilla y facilitar el acceso a la información relacionada con sus servicios.

La página web contará con una interfaz elegante, moderna y delicada, utilizando una identidad visual basada en tonos crema, rosa suave y dorado beige, en armonía con la imagen de la marca.

El proyecto se desarrolla mediante HTML, con páginas independientes y una estructura organizada que permite mantener el contenido claro, facilitar su mantenimiento y preparar la base para futuras mejoras en el diseño y la funcionalidad.
